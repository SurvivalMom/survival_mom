# survival_mom 表系動画(チェックリスト動画)制作プレイブック — MODE6

mode1〜5(AI動画生成+後入れテロップ方式)とは別系統の制作パイプライン。
Canvaで「暗めの室内・窓辺の背景動画」に白文字のチェックリストを重ねる、
16秒のInstagramリール用フォーマット。

## フォーマットの基本仕様

- 解像度：1080×1920(縦型)
- 尺：16秒を標準とする(初期は8秒だったが、視聴維持率データに基づき16秒へ延長)
- 背景：暗い高コントラスト背景。項目を1つずつテンポよく表示する
- 文字：白・ゴシック体太字。フェードインではなく、スタッガード(順番にスナップイン)表示
- 音声：トレンドBGM(スロー・感傷系)を推奨
- 投稿時間：20時以降を推奨

## 構成(固定テンプレート)

1. タイトルカード(「〇〇な7つの夜/瞬間/理由/痛み」等の形式)
2. 「こんなこと、ありませんか？」の導入テロップ
3. ①〜⑦のチェックリスト項目
4. 締めテロップ：
   - 自己肯定/自己への許可の一文(必須。「あなたのせいじゃない」「それだけ頑張っている証拠」等)
   - 保存CTA：「保存して、また見返してください。」
   - フォローCTA：「続きが気になる人は、フォローしてお待ちください。」

## 絶対ルール

- **STEP1→2→3のような「解決手順」形式は禁止**(自己責任を再度背負わせる構造になるため)
- 自己肯定・許可の一文を必ず入れる(「〜しなくていい」「あなたのせいじゃない」等)
- Unique(独自視点)／Specific(具体的な場面)／Authentic(現場のリアリティ)の3条件を満たす

## CTA配置のセーフゾーン(Instagram UI対策)

1080×1920キャンバスで、以下の帯にテキストを置かない：

- 上部 0〜150px：ステータスバー等
- 下部 1620〜1920px(下から300px)：アカウント名・キャプション・音源情報
- 右端 960〜1080px(右から120px)：いいね・保存・シェアのアイコン列

安全エリアは x:0〜960px, y:150〜1620px。Canvaでは「定規とガイド」でこの範囲に
ガイド線を引いて配置を確認する。

## ピン留めコメントのルール(コメント誘導型エンゲージメント)

③④の分析で「視聴完了率は高いが保存数が伸びない」課題が見つかったことを受け、
全テーマ共通で以下の定型コメント誘導フォーマットを採用：

```
(フォローしてくれた方、ありがとうございます)
いくつ当てはまったか、数字だけでも置いていってください。
そのあと、すぐ上のコメントに一言重ねてから、
[テーマ固有の問いかけ]を聞かせてください。
アドバイスはいりません。
```

「アドバイスはいりません」を明記することで、Instagramコメント欄が安易な
助言合戦にならず、共感の表明だけで気軽にコメントできる設計にしている。
保存だけでなくコメント・返信スレッドという別のエンゲージメント経路を確保する狙い。

## 投稿順の推奨(ユーザー指定)

間口の広いテーマ(③④⑤⑧⑩)を優先的に早めに投稿し、ニッチなテーマ
(①⑥⑦ 看病・看護休暇系)は後半に回す。
