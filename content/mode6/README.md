# survival_mom 表系動画(チェックリスト動画)制作プレイブック — MODE6

mode1〜5(AI動画生成+後入れテロップ方式)とは別系統の制作パイプライン。
Canvaで「暗めの室内・窓辺の背景動画」に白文字のチェックリストを重ねる、
10〜16秒のInstagramリール用フォーマット。

## フォーマットの基本仕様

- 解像度：1080×1920(縦型)
- 尺：16秒を標準とする(初期は8秒だったが、視聴維持率データに基づき16秒へ延長)
- 背景：暗めの室内・窓辺など、低コントラストにならない統一感のある動画素材
- 文字：白・ゴシック体太字。フェードインではなく、スタッガード(順番にスナップイン)表示
- 音声：Instagramのトレンド音源を優先的に使用

## 構成(固定テンプレート)

1. タイトルカード(2行程度、「〇〇な7つの夜/瞬間/理由」等の形式)
2. 「こんなこと、ありませんか？」の導入テロップ
3. ①〜⑦のチェックリスト項目(1項目は実際に使えるフレーズ/一言を含める。2026-11-02の
   保存数分析以降、必須項目として追加)
4. 締めテロップ：
   - 自己肯定/自己への許可の一文(必須。STEP形式的な解決提示は禁止)
   - 保存CTA：「理由付き」にする(例：「次に同じ場面が来た時のために」)
   - フォローCTA

## 絶対ルール

- **STEP1→2→3のような「解決手順」形式は禁止**(自己責任を再度背負わせる構造になるため)
- 自己肯定・許可の一文を必ず入れる(「〜しなくていい」「気づかなくていい」等)
- Unique(独自視点)／Specific(具体的な場面)／Authentic(現場のリアリティ)の3条件を満たす

## CTA配置のセーフゾーン(Instagram UI対策)

1080×1920キャンバスで、以下の帯にテキストを置かない：

- 上部 0〜150px：ステータスバー等
- 下部 1620〜1920px(下から300px)：アカウント名・キャプション・音源情報
- 右端 960〜1080px(右から120px)：いいね・保存・シェアのアイコン列

安全エリアは x:0〜960px, y:150〜1620px。Canvaでは「定規とガイド」でこの範囲に
ガイド線を引いて配置を確認する。

## 保存率改善テスト(2026-11-02〜)

視聴完了率が高い動画でも保存数が0のままという課題に対し、以下を仮説として
③以降のテーマに反映：

1. チェックリストの1項目に、実際に使い回せるフレーズ・一言を含める
2. 締めのCTAに「保存する理由」を明記する(「次に同じ場面が来た時のために」等)

効果検証中。
