# リールを仕上げたあとの冒頭チェック（両アカウント共通）

リール動画を仕上げたら、投稿する前に「冒頭6秒チェッカー」（`hook_yosoku.html`、公開ページ https://survivalmom.github.io/survival_mom/hook_yosoku.html ）と同じ採点をかけ、冒頭で離れられそうなところを直してから渡す。

## 手順
1. 動画を仕上げる（care_design_lab は `content/caredesign/_playbook/lt_reel.py`）
2. 採点をかける
   ```
   python3 content/_playbook/hook_check.py 完成.mp4 --brand sm|cdl --theme "伝えたいこと" --out 結果.json
   ```
   - `--brand`：survival_mom_diary は `sm`、care_design_lab は `cdl`
   - アプリの「🎬動画」と同じく、0〜6秒の13枚の静止画だけを送る（動画そのもの・音声は送らない）
   - 採点の文言とペルソナは、毎回 `hook_yosoku.html` から読み込む。アプリを直せば、自動チェックにもそのまま反映される
3. 判定（アプリと同じ目安）。台本の段階から「結末チラ見せ」型（`content/caredesign/_playbook/reel-telop-handoff.md` §7）で作っておくと、ここで直す量が減る
   - **65%以上**（このまま出せる）→ そのまま渡す
   - **64%以下** → 「離れやすい瞬間」「直すとよいところ」「言い換え案」をもとに、映像を作り直さずに直せるところ（冒頭のタイトルカードの言葉と行数、字幕の位置、6秒までの続きの予告、画面をゆっくり寄せる動き）を直して、もう一度採点する。やり直しは2回まで
   - 2回直しても65%に届かないときは、作り直さずに、結果と、映像から作り直す場合の案をユーザーに見せて判断してもらう
4. 記録する：スプレッドシート（ID: 1noRJWcQR7muqEXVCORtfo4RjOk4Czaa_QBz3ytT0Xpg）の「冒頭チェック」タブに、投稿日・アカウント・タイトル・何回目・6秒残存の予測・見立て・離れやすい瞬間・直したこと、を1回ごとに1行で書く
5. ユーザーに渡すときは、最終の点数と、直したことを一言添える

## 気をつけること
- この点数は予測で、実際の視聴データではない。投稿後に、実際の平均視聴時間と3秒以内のスキップ率と比べて、予測がどれくらい当たるかを見ていく
- 窓口（`workers/ai-proxy.js`）は、公開ページ以外からの呼び出しを合言葉ヘッダー `x-sm-key` で受け付ける。設定は `workers/README.md` の「ステップ5」
- 採点のたびに窓口の Gemini の利用量を使う。1本あたり最大3回（最初＋やり直し2回）まで
