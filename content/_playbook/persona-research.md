# 動画を作る前の悩みリサーチとテーマ候補の出し方（両アカウント共通）

毎週、台本・動画を作る前に、各アカウントのペルソナが今どんなことで悩んでいるかを
Instagram・TikTok・YouTube・note から探し、その声をもとにテーマ候補を出す。
テーマは「作り手が言いたいこと」ではなく「ペルソナがもう口にしている悩み」から選ぶ。

## 1. 媒体ごとに、拾う悩みと見る場所を変える
媒体によって、悩みの深さと感情の出方が違う。媒体ごとのシグナルを使い分ける。

| 媒体 | 拾える悩み | 最も見るべき場所 |
| --- | --- | --- |
| Instagram | 理想と現実のギャップ、日常のモヤモヤ | 保存数が多い投稿、コメント欄の質問、伸びているカルーセルの1枚目（表紙） |
| TikTok | 言語化前の本音、強い共感や愚痴 | コメント欄の「わかる」「うちも…」の連鎖と反論、検索サジェスト、再生数に対してコメントが多い動画 |
| YouTube | 解決策を能動的に探している、明確な悩み | 検索サジェスト（「テーマ あ」「テーマ い」…）、人気の長尺動画のコメント欄、バズ動画のサムネの強い言葉 |
| note | 言語化された深い葛藤、構造的な課題 | スキが多い体験談の「一番つらかった瞬間」、有料記事のタイトル・導入文・目次 |

### Instagram：日常のモヤモヤと「保存したい解決策」
- 同じテーマで伸びている投稿のコメント欄を見る。「これ、まさに私のことです」「〇〇の場合はどうすればいいですか？」は、そのまま企画の種になる
- 悩み系のハッシュタグで探す：テーマ名に加えて `#〇〇の悩み` `#〇〇辞めたい` `#〇〇あるある`
  - care_design_lab の例：#介護主任の悩み #介護辞めたい #介護リーダーあるある #施設長の悩み
  - survival_mom_diary の例：#不登校ママの悩み #不登校あるある #中学受験辞めたい #発達グレーあるある
- いいね・コメントが多いカルーセルの1枚目の言葉を書き写す。ペルソナが指を止めた「痛みの言葉」が詰まっている

### TikTok：言語化できていない生の本音・愚痴
- コメント欄で「わかる」「うちの〇〇もこれ」と共感が集まっている箇所＝共通の痛み
- 「でも現場では無理」のような反論コメント＝今ある解決策では越えられない本当の壁。テーマ候補として特に重視する
- 検索窓の予測変換と「他の人はこちらも検索」に出る言葉＝今まさに多くの人が検索している関心事
- 再生数に対してコメントが多い動画＝自分ごととして語らずにいられない悩みを扱っている

### YouTube：解決意欲が高い明確な悩み
- 検索サジェストを「あいうえお順」で洗う（「介護 主任 あ」「介護 主任 い」…）。「〇〇 対処法」「〇〇 コツ」「〇〇 しんどい」のような具体的な悩みが出る
- 人気動画のコメント欄を「新しい順」「評価順」で読む。「自分の場合はこういう状況なのですが…」という長文の相談に、動画で触れられていない悩みがある
- 登録者数以上に再生されている動画のサムネの強い言葉を書き出す

### note：深い葛藤と「お金を払ってでも解決したい課題」
- 「〇〇 限界」「〇〇 失敗」「〇〇 悩んでいたこと」で検索し、人気順（スキが多い順）で体験談を読む。「一番つらかった瞬間」の描写を抜き出す
- 有料記事の無料部分（タイトル・導入文・目次）を見る。「こんな悩みありませんか？」と整理されている悩みは、読者がお金を払ってでも解決したいもの

## 2. 生のフレーズのまま残す
見つけた悩みは、自分の言葉で要約しない。ユーザーが実際に使っていた言葉のまま残す。
- ×「業務効率化したい」 → ○「申し送りだけで毎日30分残業になるのがしんどい」
- ×「不登校の対応に悩んでいる」 → ○「朝、玄関まで来て止まる。毎朝それを見てるのがしんどい」
- そのままタイトルや冒頭のフックに使える細かさで残す。1フレーズは短く（目安60字まで）
- 名前・学校名・施設名・地域など、個人が特定できる情報は書かない。アカウント名も書かない（URLは残してよい）
- 台本・キャプションでは、フレーズの言い回しや場面は使ってよいが、他人の長い文章を丸写ししない

## 3. 誰が・どこまで集めるか
このリサーチは、ログインが必要な場所が多い。クラウドの自動実行と、ログインしたブラウザ（Chrome）で分担する。

### 自動実行（毎週日曜の朝、クラウド）でできること
2026-11-24 に試した結果、クラウドから直接取れないもの：note のスキ数（自動アクセスを断られる）、YouTube の検索サジェスト（通信制限）、Instagram・TikTok・YouTube のコメント欄と保存数（ログインが必要）。
- WebSearch で媒体をしぼって検索し、検索結果に出る本文・説明文・タイトル・ハッシュタグから悩みの言葉を拾う
- note は検索に出た体験談を読み、「一番つらかった瞬間」を抜き出す
- YouTube はタイトルから、強い言葉と、どんな悩みに答える動画が多いかを拾う
- 「生の声」タブの、直近7日に集めた行をすべて読み、優先して使う

### ブラウザ（Chrome）で集めるもの（できる週だけ・任意）
Claude in Chrome など、ログインしたブラウザで上の「最も見るべき場所」を見て、スプレッドシートの「生の声」タブに書く。
- **1つの媒体につき、1アカウントあたり5件まで**（例：Instagram と TikTok で5件ずつ）
- 当事者が自分の悩みを書いているものを選ぶ。支援者の宣伝や「〜する方法」の投稿は除く
- 悩んでいる場面（いつ・どこで・何が）が書かれているものを優先する
- 5件のほとんどが同じ悩みでテーマの幅が出ないときや、休み明け・年度末など悩みが変わる時期だけ、10件まで増やしてよい
- 件数を抑えるのは、ログイン中のアカウントで大量にページを開くと、サービス側に機械的な操作と判断されるおそれがあるため
- 日曜の朝の自動実行より前（土曜まで）に書いておくと、その週のテーマ候補に入る

「生の声」タブの列：集めた日／アカウント／媒体／どこで見たか（コメント欄・サジェスト・表紙・目次など）／生のフレーズ／場面／シグナル（保存数・「わかる」の連鎖・スキ数・反論など）／URL／テーマに使った日

## 4. まとめる
拾った声を似たものどうしでまとめる。
- **悩み**：一番強い生のフレーズを1つ選ぶ
- **場面**：その悩みが起きている具体的な場所・時間・物（例：朝の玄関、夜勤明けの申し送り）
- **シグナル**：何件の声で見たか、どの媒体のどのシグナルか（例：TikTok コメントで「うちも」が連鎖、note 体験談 3本）
- **根拠URL**：2本以上
- 反論や「でも無理」の声があれば、別に書いておく（今ある解決策で越えられない壁）

## 5. テーマ候補を出す
アカウントごとに5つ。それぞれに次をそろえる。
- テーマ案（その回のタイトルになる言葉。生のフレーズをできるだけ活かす）
- ペルソナの悩み（生のフレーズのまま）
- 映像にできる場面（顔を映さず、手・背中・物で見せられるか）。見せられないものは候補にしない
- 意見が割れる二択案（👍／🙌）。反論の声があるテーマは、その対立をそのまま二択にする
- おすすめ度 A/B/C：媒体をまたいで同じ悩みが出ているか・シグナルの強さ（保存・共感の連鎖・スキ）・具体的な場面の有無・既存の台本と重ならないか、で決める

既存の台本（content/caredesign/ai-video/、content/mode2/）とスプレッドシートの過去分と、テーマが重ならないことを確かめる。
