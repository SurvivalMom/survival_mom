# MODE 4：ループ動画化（CapCut手順）火曜「帰省前に考えていること」5つ

対象素材：content/mode3/2026-08-04_kisei-script-infographic.md のnanobanana画像（テキスト込み）

仕様：5秒シームレスループ・Lo-fi BGM・冒頭に「誰向けか」を伝えるナレーションあり・
テキストは画像に内蔵済みのため追加テロップなし

## ナレーション原稿

```
JP: 不登校の子と、そのきょうだいを育てているお母さんへ。帰省前に考えていること、5つにまとめました。
Romaji: Futoukou no ko to, sono kyoudai wo sodatete iru okaasan e. Kisei mae ni kangaete iru koto, itsutsu ni matomemashita.
```

## CapCut手順
1. PNG（テキスト込み）を読み込み → 9:16 → 5秒にトリム
2. 「アニメーション」→「ズームイン（極小）」→ 最も遅い速度
3. 「オーディオ」→「楽曲」→「lofi」または「calm」で検索
4. BGMを5秒にトリム・1拍目を0秒に合わせ、音量を40%程度に下げる（ナレーションを聞き取りやすくするため）
5. 「オーディオ」→「音声」→上記ナレーション原稿を別録りしたファイルを0秒から配置
6. ナレーションの再生時間に収まるようBGMとの音量バランスを調整
7. BGM末尾にフェードアウト0.2秒
8. 1080p・30fpsでエクスポート
