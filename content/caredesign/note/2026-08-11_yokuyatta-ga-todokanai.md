## 1. タイトル

## 2. 無料部分

お盆で人手が薄い現場、あなたは部下に「よくやった」と声をかけていませんか。

想定してみてください。3人がお盆休みに入り、いつもより少ない人数で夜勤を回した朝。
新人が、慣れない業務をひとりでやり切った。すれ違いざまに「よくやった」と声をかけたら、
相手は「あ、はい」とだけ答えて、そのまま更衣室へ向かった。会話はそこで終わった——
こういう場面に、心当たりはないでしょうか。

声はかけている。悪気もない。むしろ励ましたい気持ちで言っている。それなのに、なぜか
手応えがない。この違和感は、あなたの熱量が足りないからではありません。

「よくやった」は、行動そのものではなく、結果や能力に対する評価の言葉です。心理学の
研究では、能力や結果を褒められた子どもは、努力やプロセスを褒められた子どもに比べて、
その後の粘り強さや課題への興味が下がったという報告があります［注1］。これは本来
子どもを対象にした実験ですが、「評価されている」と感じさせる言葉が、相手の意欲を
伸ばすとは限らないという構造は、大人のマネジメントの現場でも同じように語られています。

つまり「よくやった」は、言う側は励ましのつもりでも、受け取る側には「合格点をつけられた」
ように聞こえることがある。上下関係を縮めるどころか、逆に「評価する側とされる側」という
距離を強めてしまう可能性があるのです。

では、何を変えればいいのか。答えは難しいものではありません。結果ではなく、あなたが
実際に見た「行動」を、具体的に一言添えるだけです。「よくやった」の代わりに、
「〇〇のところ、自分で判断して動いてくれたの、助かった」——このひと言に変えるだけで、
伝わり方は変わります。

具体的にどう言い換えればいいか、忙しい現場でもとっさに使えるセリフと、1週間で
試せる小さなプランを、この続きに置いておきます。

## 3. 有料部分

【ここからは有料部分】

これを開いた瞬間から、変わることがあります。声をかける前に「何が評価的で、何が
プロセスを認める言葉か」を考え直さなくてよくなります。とっさに出てきた言葉が、
また「よくやった」で終わってしまっても、次にどう言い換えればいいかがすぐわかります。

### ■書き込み式ワークシート：声かけ仕分けシート

直近1週間で部下にかけた言葉を思い出しながら、以下の表を埋めてください。

| 最近かけた言葉 | それは「評価」？「行動承認」？ | 言い換え案（自分で書く） |
|---|---|---|
| 例：よくやった | 評価 | 〇〇を最後までやり切ったの、見てた |
| （記入欄） | | |
| （記入欄） | | |
| （記入欄） | | |
| （記入欄） | | |

「評価」に丸がついた言葉が多いほど悪いわけではありません。まず自分のクセを知ることが
最初の一歩です。

### ■現場で使える声かけセリフ集（NG→OK）

- NG「よくやった」→ OK「〇〇の場面で、自分から声をかけてくれたの助かった」
- NG「すごいね」→ OK「あの対応、落ち着いて手順通りにできてたね」
- NG「さすが」→ OK「〇〇のやり方、工夫してるのが伝わった」
- NG「頑張ったね」（漠然）→ OK「大変な中、最後まで記録をやり切ったね」
- NG「助かった」（漠然）→ OK「〇〇をやってくれたから、私は他の対応に回れた」

共通しているのは、「主語が相手の行動になっているか」です。「よくやった」の主語は
あなたの評価であり、言い換え後の主語は相手が実際にした行動です。

### ■1週間声かけプラン（雛形）

| 曜日 | 声をかける相手 | 今日見た具体的な行動 | 言い換えた声かけ |
|---|---|---|---|
| 月 | | | |
| 火 | | | |
| 水 | | | |
| 木 | | | |
| 金 | | | |
| 土 | | | |
| 日（休） | — | — | — |

1日1人でかまいません。「見た行動」の欄が埋まらない日は、無理に声をかけなくて大丈夫です。
見ていないことを見たふりで褒める方が、かえって不信感につながります。

### ■想定ケース（仮定的なシナリオ・実在の人物ではありません）

ある主任が、1週間だけ「よくやった」をやめて、見た行動を一言添える言い方に変えてみた
という想定です。1日目、2日目は特に変化を感じませんでした。しかし4日目、いつもは
「あ、はい」としか返さなかった新人が、「今日はここが難しかったです」と自分から
話しかけてきました。この想定ケースが示すのは、劇的な変化ではなく、「相手が言葉を
返しやすくなる」という小さな違いです。実際の結果は、現場や相手によって変わります。

### ■よくある問いへのQ&A

**Q1：忙しくて、相手の行動を具体的に見ている余裕がない日はどうすればいいですか。**
A：見ていない日は、無理に具体的な言葉を作らなくて大丈夫です。「今日は忙しかったね、
ありがとう」のような、事実に基づく短い言葉で十分です。嘘の具体性より、正直な短さの
方が信頼を損ないません。

**Q2：年上の部下やベテラン職員にも、同じ言い方でいいですか。**
A：行動を主語にする考え方自体は年齢に関係なく使えます。ただし言葉の丁寧さやタイミング
（人前か、二人のときか）は、相手との関係性に合わせて調整してください。

**Q3：言い換えても、相手の反応が薄いままだったらどうすればいいですか。**
A：一度で関係が変わるとは限りません。ワークシートで自分の言葉のクセを記録し続けること
自体が、伝え方を見直す土台になります。

実践ワークシートで、自分の声かけを1週間分振り返る形にしています。
今のあなたの現場での「よくやった」の使い方、コメントで教えてもらえたら嬉しいです。

［注1］Mueller & Dweck (1998) は児童を対象にした実験研究であり、そのまま大人の職場に
当てはまることを断定するものではありません。
