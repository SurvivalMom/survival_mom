# 引き継ぎメモ：CARE DESIGN LAB リール制作（2026-11-20）

claude.ai のチャットで決めたこと・作ったものの記録。
リール（AI動画）の台本を書く・直すとき、動画にテロップを入れるときは、先にこのメモを読むこと。

## 1. 決めたこと（今後の台本・動画はこれに合わせる）

### テロップは @light_kaigo 型
参考：@light_kaigo（ライト＠介護保険のスペシャリスト）
「知らなきゃ後悔する！ケアマネの選び方3選」のテロップの入れ方。

- 文字はすべて **白か黄の太字に、太い黒フチ**。背景の帯・座布団は付けない
- **タイトルカード**（冒頭）：画面中央に大きく、0.0秒から全文表示（フェード・文字送りなし）
  - 1段目：小さめの前置き（白）
  - 2〜4段目：本題（強調する語だけ **黄・最大**、ほかは白）
  - 5段目：小さめのつぶやき（白、「〜」で終える）※裏シリーズのみ
  - 表示時間：裏シリーズ 0〜4秒／若いリーダー（セリフ劇）0〜3秒
  - カード表示中は字幕・ラベルを出さない
- **字幕**：画面の中ほどより下。白文字＋黒フチ。要点の語だけ黄色
- **若いリーダーのScene 3のポイント**：①〜③を1つずつ、字幕より一回り大きく画面中央に。
  番号と要点の語を黄色（ライトさんの「②メールやLINEなど多様なツールが使える」と同じ）
- **左上のタイトルラベル**：カードが消えてから最後まで。黄色の帯に黒文字で
  「（各回のタイトル） ▶」
- 赤地に黄文字の「上部固定ヘッダー」はやめた

### 最後は意見が分かれる二択
- 主CTAは **保存** のまま。最後の2秒は保存の依頼に替えて二択の問いかけを出す
- 絵文字は **👍 と 🙌** にそろえる（🙅 は「ダメ」に見えるので使わない）
- 「できる・できない」の自己申告ではなく、現場で意見が割れる二択にする
- キャプションの最後にも同じ二択を入れる

### ループ構成
- 最後の画を、Scene 1 と同じ画角に戻して2周目につなげる

### 若いリーダー01だけの追加
- 冒頭で「リーダーは指示を出すもの」という思い込みを1行で否定する
  （否定するのは人ではなく考え方。年上職員・ベテランを責めない）
- Scene 3 の頭に管理者の言い切り「指示、出さなくていいのよ。」

## 3. 動画の仕上げ手順（裏シリーズ）

Gemini の「動画を作成」（縦向き 9:16）で、3シーンを1本の約30秒の動画として生成し、
そこから3〜4か所を切り出して約14.5秒にしている。

### 切り出し秒数（元動画 → 完成版）
- ura-12：2〜6秒 → 0〜4秒／13〜18秒 → 4〜9秒／21.5〜27秒 → 9〜14.5秒
- ura-13：3〜7秒 → 0〜4秒／11〜16秒 → 4〜9秒／21.5〜25秒 → 9〜12.5秒／28〜30秒 → 12.5〜14.5秒（ループ）

### テロップの重ね方
- テロップは Python（Pillow）で 720×1280 の透過PNGを場面ごとに作り、ffmpeg で重ねる
  - 0〜4秒：タイトルカード
  - 4〜9秒：Scene 2 の字幕＋タイトルラベル
  - 9〜12.5秒：Scene 3 の字幕＋保存の依頼＋タイトルラベル
  - 12.5〜14.5秒：Scene 3 の字幕＋二択＋タイトルラベル
- フォント：Noto Sans CJK JP Black（index 0）／絵文字：Noto Color Emoji
- サイズの目安：前置き 40px（フチ6）／本題 80px（フチ9）／最大の強調語 112px（フチ11）／
  字幕 46px（フチ7）／保存の依頼 28px（フチ5）／二択 38〜40px（フチ6）／ラベル 26px
- 色：白 #FFFFFF、黄 #FFE400、フチ 黒
- 切れ目の音のプツッを防ぐため、各区間の頭と終わりに 0.05〜0.15秒の音のフェードを入れる

### 環境音
- Gemini の元動画は音が小さい（平均 -49dB 前後）
- ffmpeg で `volume=12dB,alimiter=limit=0.35:level=disabled` → 平均 -38dB、最大 -10.6dB
  （`level` を有効にすると自動で音量が上がりすぎるので無効にする）

### Gemini で生成するときの注意
- 同じチャットで続けて生成すると「Something went wrong」で失敗することがあった。
  新しいチャットで生成し直す
- Scene 2・3 を別々に生成するときは、「Same setting as Scene 1」では伝わらないので、
  場面の説明（夜の事務所・デスクライト・木の机・手書きの日本語の申し送り記録）を毎回書く

## 4. 参考にした分析（要点）
- @light_kaigo のリールで最も伸びたのは、意見が割れることを言い切る型
  （「時代遅れなケアマネ」：21万再生、27秒、主張1つ、コメント110件）
- リスト型（「ケアマネの選び方3選」：2.1万再生）は、答えを先に全部見せる・
  最後に質問・最初の画に戻るループ、が効いていた
- 否定する相手は「人」ではなく「考え方」にすると、炎上しすぎずに議論が起きる

## 5. テロップ配置のヒント（2026-11-26 追加）
参考：TikTok「テロップを真ん中に置いてる人、今すぐやめてください」（約41秒）の内容を、顔を映さない（手元・物だけの）この型に読み替えたもの。
再生数への効果は検証されていない（動画内の「448→16.4万」も動画の主張）。効いたかどうかは、平均視聴時間と3秒以内のスキップ率で確かめる。

| 動画のヒント | この型での使い方 |
| --- | --- |
| 字幕の定位置は、真ん中より少し下 | 字幕の基本位置は 720×1280 基準で y=700（高さの約55%）。これまでどおり |
| ずっと同じ位置だと飽きてスキップされる。編集で変化をつける | 場面ごとに、主役の物（手・ノート・湯呑みなど）と重ならない側へ字幕を動かす。物が下にあれば上（y=300前後）、物が上なら下 |
| 悩みを代弁するときは、画面を暗くして、ネガティブな言葉をど真ん中に | 冒頭のタイトルカード（0〜4秒）は、画面全体を少し暗くして（黒35%）中央に置く。カードは悩みの一言（逆説）にする |
| 2つの言葉を比べるときは、左右に色違いのテロップ | 最後の二択は左右に並べ、👍の答えは黄（#FFE400）、🙌の答えは白にする |
| ズームして人を片側に寄せ、空いた側に縦書きのキーワード | 映像を作るときの指示に「主役を画面の片側に寄せる」場面を1つ混ぜ、空いた側に縦書きのキーワードを置く（今後試す） |

### スクリプト
- `lt_reel.py`：4場面のAI動画（12〜15秒）に、この型のテロップ・ループ・音量調整をまとめて入れる
  - 使い方：`python3 lt_reel.py spec.json 元動画.mp4 完成.mp4`
  - spec の主なキー：`label`（左上ラベル）、`card`（前置き・本題・つぶやき）、`s2`〜`s4`（字幕）、`cta`（保存の依頼）、`choice`（二択）、`t2`〜`t4`・`end`（場面の切れ目の秒）、`card_dim`（カードの暗さ、既定0.35）、`s2_y`〜`s4_y`（場面ごとの字幕の高さ）、`gain_db`（音量）、`blur`（ぼかす範囲）
- `telop_overlays_example.py`：ura-13 の完成版で使った元のスクリプト（参考）
