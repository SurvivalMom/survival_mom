# AI動画（情景独白型・裏シリーズ）：消えた自分の字

## メタ情報
- 形式：情景独白型（裏シリーズ。人物発話なし、物のクローズアップとテロップのみ）
- 裏シリーズ：「裏・申し送りノート」#2
- 表ペア：dokuhaku-03-shijimachi「『指示待ち』にしたのは誰か」
  （管理者視点：先回りして答えを教えるほど部下は指示待ちになる、というテーマを、
  今回は指示を待つ側の内面から描く）
- 登場人物：なし。手のみ、顔・名札は映さない
- テロップ・BGMなし。ナレーション・セリフなし
- 尺目安：12〜15秒
- 主CTA：保存
- 参考元：既存dokuhaku-03と同一の指導ノートというモチーフを再利用し、裏側の
  視点として独自に構成

## タイトル
消えた自分の字

## キャプション
指導ノートを見返したら、
自分の字が、どこにも見当たらなかった。

## ハッシュタグ

## ピン留めコメント（バトンパス型）
このノートは、気づけば「聞く前に答えが来る」ことに慣れてしまった人へ。
同じ気づきを持つ人が、隣の現場にもいるかもしれません。

## シーン構成

**Scene 1（0〜4秒）**
（後編集で「気づけば、ノートの字が全部、先輩のものになっていた。」のテロップを表示）
```
Vertical 9:16 cinematic, realistic care facility break room interior,
soft daylight, natural ambient sound only, no music, no on-screen
captions. Close-up on a spiral guidance notebook, an anonymous hand
flipping through page after page filled entirely with one person's
handwriting -- no blank space, no other handwriting visible. No face
visible, no name badges.
```

**Scene 2（4〜9秒）**
（テロップ切り替え：「最後に自分で書いたのは、いつだっただろう。」）
```
Same setting. The hand flips backward through earlier pages, searching,
slowing down, scanning each one. Natural ambient sound only, no music,
no captions. No face visible.
```

**Scene 3（9〜13秒）**
（テロップ：「聞かれる前に答えが来るから、考えなくなったのかもしれない。」
続けて主CTA「保存して、次に答えを渡される前に、少しだけ自分で考えてみてください。」
を小さく添える）
```
Same setting. The hand holds a pen above a blank line at the end of the
notebook, pauses, then closes the notebook without writing anything.
Quiet, unresolved mood. No face visible, no music, no captions. Leave
the lower third of the frame clean for text to be added later.
```
