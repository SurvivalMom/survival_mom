## 第0章：イントロ（3スライド）

**Slide 0-1（タイトル）**
```
介護離職予兆 入門講座
```
ナレーション：これから、一緒に学んでいきましょう。テーマはただ一つ、
「辞める前に、数字に出る」という問いです。

**Slide 0-2**
```
「また1人、辞めてしまいました」
——退職は、本当に「突然」でしょうか。
```
ナレーション：そう報告を受けたとき、多くの経営者は驚きます。でも実は、
辞める前には必ず小さな異変が起きています。この講座では、その異変の
捉え方を学びます。

**Slide 0-3**
```
この講座で学ぶ5つのSTEP
①数字を見る　②行動を見る　③関係を見る
④対話する　　⑤経営数字に変える
```
ナレーション：この5つを、順番に見ていきます。

## 第1章：STEP1 数字を見る（4スライド）

**Slide 1-1（章タイトル）**
```
STEP1：数字を見る
```

**Slide 1-2**
```
見るべき4つの数字
①欠勤・有休取得の増加
②残業時間の偏り
③シフト変更の申し出の増加
④ヒヤリハット報告の変化
```
ナレーション：この4つは、感情や印象に頼らず確認できる、最も客観的な
指標です。

**Slide 1-3（想定例）**
```
想定例：ある職員の有休取得が、先月から急に増えていた。
本人に理由を聞くまで、経営者は気づいていなかった。
```
ナレーション：これは想定例です。数字を月次で見る習慣がなければ、
こうした変化は埋もれてしまいます。

**Slide 1-4（まとめ）**
```
数字は、感情より先に異変を教えてくれる。
```

## 第2章：STEP2 行動を見る（4スライド）

**Slide 2-1（章タイトル）**
```
STEP2：行動を見る
```

**Slide 2-2**
```
見るべき行動のサイン
①会議での発言が減った職員はいないか
②申し送り・報告の頻度は変わっていないか
③新人からの質問が減っていないか
④職員同士の会話量に変化はないか
```
ナレーション：数字にまだ出ていなくても、行動には変化が先に表れることが
あります。

**Slide 2-3（想定例）**
```
想定例：いつも質問の多かった新人が、最近何も聞いてこなくなった。
「慣れてきたのかな」で見過ごされていた。
```

**Slide 2-4（まとめ）**
```
行動は、数字より早く変化を教えてくれることがある。
```

---

## 第3章：STEP3 関係を見る（4スライド）

**Slide 3-1（章タイトル）**
```
STEP3：関係を見る
```

**Slide 3-2**
```
組織の分断を見つける視点
①管理者と現場で、意見の食い違いを感じたことはないか
②管理者自身が疲弊しているサインはないか
③「特に問題ありません」の裏側を、具体的に聞けているか
```
ナレーション：個人の問題に見えることも、実は組織の中の「分断」が
原因であることがあります。

**Slide 3-3（想定例）**
```
想定例：管理者からの報告は「順調です」の一言だけ。
実際に現場を歩くと、管理者と職員の間に距離を感じた。
```

**Slide 3-4（まとめ）**
```
関係の分断は、個人の問題より先に組織の問題として現れる。
```

## 第4章：STEP4 対話する（4スライド）

**Slide 4-1（章タイトル）**
```
STEP4：対話する
```

**Slide 4-2**
```
退職の決定後ではなく、違和感の段階で聞く。
```
ナレーション：ここまでのSTEPで気づいた異変は、放置すれば意味が
ありません。小さな違和感のうちに、対話に移します。

**Slide 4-3**
```
事実で伝えるSBIモデル
S（状況）：いつ・どこで
B（行動）：何をした・何が起きたか
I（影響）：それがどんな影響を与えたか
```
ナレーション：感情ではなく事実で伝えることで、相手は反発せず
受け止めやすくなります。

**Slide 4-4（まとめ）**
```
対話は、感情ではなく事実から始める。
```

## 第5章：STEP5 経営数字に変える（4スライド）

**Slide 5-1（章タイトル）**
```
STEP5：経営数字に変える
```

**Slide 5-2**
```
現場の異変を、経営の言葉に翻訳する。
採用費／教育費／現場の調整コスト
```

**Slide 5-3**
```
見えない損失は、静かに積み上がっている。
新人1人を失うと、外部データの試算で約90万円規模。
（採用コストに関する公開データをもとにした試算）
```
ナレーション：これは断定的な保証ではなく、外部データに基づく試算です。
それでも、感覚ではなく数字として捉える意味は大きいはずです。

**Slide 5-4（まとめ）**
```
「問題が起きてから対応する経営」から、
「小さな異変の段階で気づき、対話する経営」へ。
```
